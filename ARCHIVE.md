# What is on GitHub

The public tree is a run-kit plus the current tests. Clone it, install deps, run `just check`, `just test`, `just dash`.

The agent factory has been removed from this repo. Its code, run history, specs and requests are in `archive/factory-2026-09-02/` (gitignored). Do not add `adws/` back.

Extra docs and old batteries were moved to `archive/` (gitignored). The old SSSF justfile is `archive/justfile.sssf`. The tracked justfile is app recipes only.

Do not restore extras to GitHub.
